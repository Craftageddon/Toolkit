# Security and scope

This public repository contains only reusable source, specifications and sample/test geometry. Do not commit customer records, credentials, phone/device backups, production CAD drawings, signing keys, tokens, payment data, or proprietary company files.

MCP integrations may run arbitrary code with the privileges of the host account. Install and test them in a confined environment on disposable files. No script in this toolkit should be run without local review; nothing is auto-installed on Windows.

The Android/AYN Thor revision 1.1 103-package roadmap is **reference-only**, and is not being implemented or flashed by this toolkit.

Report suspected security problems privately to the repository owner. Avoid posting access tokens or exploit details in public issues.
